# Habitzz – Micro Habit Reminder App
![image alt](https://github.com/RupakDas12/Habitzz/blob/6e1361435e10a600c6e839ad8e942c3ddb74a8fd/Screenshot%202026-02-27%20114936.png)

## ✨ Features
- Daily micro habit tracking
- Push notifications reminder
- Progress analytics dashboard
- Supabase authentication & database
- Streak tracking

## 🛠 Tech Stack
- React Native (Expo)
- Supabase (Auth + PostgreSQL)
- TypeScript
- Context API
- Notifications API

## 🏗 Architecture
- Context for global state
- Supabase client in lib
- Notifications service
- Tab navigation structure

Short reflection: performance, state management, async handling, etc.
